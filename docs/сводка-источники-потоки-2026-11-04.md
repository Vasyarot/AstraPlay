# AstraPlay: источники и получение видеопотоков — 4 ноября 2026

## Что изменено

- В список фильмов добавлены **«Мосфильм · RUTUBE»** и **«Ленфильм · RUTUBE»**: два каталога официальных студий на одной платформе. Приоритет — полные русскоязычные фильмы. Ролики короче 30 минут, прямые эфиры и аудио исключены. Каталог ограничен 60 карточками и тремя запросами страниц для экономии памяти и времени.
- Карточки этих фильмов открываются нативно, в оформлении AstraPlay: название, изображение, год из названия, продолжительность, описание, избранное и отметка просмотра. Данные, которых источник не предоставил, не выдумываются.
- Добавлено получение HLS-потока RUTUBE через публичный `api/play/options/{id}`. Временная ссылка запрашивается при запуске; в карточке и очереди сохраняется постоянный адрес видео.
- Добавлено получение потоков **«Смотрим»** через публичный интерфейс нынешнего официального плеера: `https://player-api.smotrim.ru/api/v1/video/{id}`. Используется `data.streams.m3u8` только при ответе `status=OK`. Работает для фильмов и серий, на которые источник выдаёт поток без дополнительного входа.
- Основная кнопка **«Смотреть»** сначала использует встроенный плеер. Если доступен только официальный веб-плеер, он открывается внутри приложения. При ошибке воспроизведения потока с известным резервным embed-адресом приложение освобождает нативный плеер и переходит к официальному.
- Отдельная кнопка **«Плеер источника»** сохраняется и позволяет сразу выбрать официальный embed для поддержанных вариантов. Полная страница остаётся отдельным действием пользователя.
- Исправлено падение в списке источников при нажатии влево, когда фокус находится на дочернем элементе карточки: позиция определяется через содержащий её ViewHolder.

В проверках RUTUBE расход памяти процесса PSS составлял около 90–117 МиБ. Для фильма и серии «Смотрим» — около 108–128 МиБ. Это короткие проверки запуска, звука и перемотки; длительный просмотр, разные прошивки и все фильмы каталогов не проверены. На устройстве с малой памятью сохраняется ограничение качества до 720p и ограниченный буфер.

Проверены загрузка настоящего каталога, нативная карточка без WebView, управление влево с вложенного элемента карточки. Пройдены проверки карточки с 1000 серий и перехода с кнопки фильма в PlayerActivity. Проверка автоперехода на локальном тестовом видео в повторном запуске пропущена, поскольку тестовый видеосервер не запускался; она проходила в предыдущем этапе работ.

54 модульных теста проходят. Lint: 0 ошибок; существующие предупреждения проекта остаются. Подробные журналы — в `build/native-sources/` (локальные артефакты, не часть исходников).

## Ограничения и дальнейшая работа

- Это не означает готовую поддержку прямых потоков всех старых сайтов. Для Filmix, HDRezka, Seasonvar и других нужны отдельные обработчики текущих плееров и проверки. Общий разбор HTML извлекает только явно опубликованные медиаресурсы.
- Проверенный iframe Filmix в этой сессии вернул HTTP 404 даже после загрузки актуальной страницы. Работа его прямого потока не подтверждена.
- Часть серий «Смотрим» возвращает `VIDEO_DISALLOW_TARIFF` и не содержит адреса потока. Проверенный пример: «Рожденные в СССР», видео 6082985. Для такого ответа сохраняется официальный плеер; обход подписки или защиты не реализуется.
- Флаг DRM и недоступные потоки не преобразуются в фиктивные прямые ссылки.
- Запросы данных ограничены по времени и размеру, отменяются при уходе с экрана; HTML и JSON целиком с ресурсами страницы в карточке не исполняются. Это описание конкретных изменений, а не заключение о полном аудите безопасности проекта.
