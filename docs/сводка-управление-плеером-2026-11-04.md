# Черновая правка плеера — 4 ноября 2026

По уточнению пользователя изменены только расположение управления и шаг перемотки.

- Воспроизведение/пауза и кнопки перемотки перенесены в нижнюю панель, рядом со шкалой и остальными действиями. Кнопки и время не перекрываются; строка действий прокручивается при нехватке ширины.
- Исправлена перемотка на шкале с пульта. `DefaultTimeBar` по умолчанию использовал длительность видео / 20, поэтому для полного фильма скачок составлял минуты. Теперь `setKeyTimeIncrement` получает тот же шаг из настроек, что кнопки плеера (по умолчанию 10 секунд). Пользовательские настройки шага сохранены.
- Дополнительные кнопки звука, субтитров и прочего на панель не добавлялись после уточнения пользователя; эти действия остаются в существующих настройках.

Проверка: 54 модульных теста, lint без ошибок, 3 теста на подключённом ТВ. На настоящем видео проверен переход по шкале с 20-й на 30-ю секунду, нижнее положение кнопок, автопереход серии, освобождение декодера при сворачивании, восстановление позиции. Снимок экрана: `build/native-player-test/player-bottom-controls.png`.

Сборка: `dist/AstraPlay-0.03-player-controls.apk`, версия 0.03 (7). Предыдущие изменения источников и карточек включены.
