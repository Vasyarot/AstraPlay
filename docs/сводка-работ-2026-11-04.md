# Сводка работ за 4.11.2026 — восстановление экранов, таймеры, навигация, баннеры

## Сделано

### 1. Восстановление последнего экрана (свернул → развернул)
- Новое: `core/LastScreen.kt` + записи маршрута в экранах + `HomeActivity.tryRestoreLastScreen()`.
- Работает и после убийства процесса системой, и после сброса стека лаунчером (через `onNewIntent`).
- Восстанавливаются: поиск (с введённым запросом), карточка TMDB, карточка источника, каталоги, IPTV, избранное/история, торренты.
- Плееры тоже: фильм/сериал продолжается с сохранённой позиции (позиция подтягивается из базы), телеканал открывается на живом эфире.
- TTL 15 минут (`TTL_MS` в LastScreen.kt), подсказка-тост «Возвращаемся к последнему экрану…».

### 2. Таймер включения
- Новое: `core/WakeTimer.kt` + `tv/WakeReceiver.kt`, настройки в «Настройки → Таймер включения».
- Режимы: «Выкл», «Каждый день в ЧЧ:ММ», «Одноразово через N минут» (1–1440).
- По таймеру включается самый первый канал IPTV; работает через AlarmManager даже при закрытом приложении; переживает перезагрузку приставки.
- Проверено вживую: будильник сработал в 02:11 и сам включил канал.

### 3. Таймер сна «как в системе»
- Меню плеера (ОК) → «Таймер сна» → «Как в системе • N мин бездействия».
- Пауза видео после того же времени бездействия, что и таймаут экрана Android; сбрасывается любым нажатием пульта; выбор запоминается (`Prefs.sleepSyncSystem`).
- Действует на фильмы/сериалы и телеканалы. Если в системе «не выключать экран» — пункт не показывается.

### 4. Баннеры сайтов
- В «Фильмы и сериалы» текстовые подписи заменены цветными баннерами с фирменными цветами: LostFilm — красный, Filmix — оранжевый, HDRezka — синий, Zona — фиолетовый, Seasonvar — зелёный и т.д.
- В фокусе: полная насыщенность + белая рамка + лёгкое увеличение — фокус видно сразу.

### 5. Оптимизация скорости (1 ГБ RAM)
- Дисковый кэш лент источников (`core/DiskJsonCache.kt`): повторное открытие экрана — мгновенно, без сети; лента старше 30 минут показывается и тихо обновляется в фоне; «Обновить ленту» бьёт в сеть.
- Дисковый кэш карточек источников: повторное открытие мгновенно (TTL 3 часа), «Обновить» в карточке — из сети.
- Отрисовка: убран crossfade постеров, отключены анимации вставки RecyclerView, focus-drawable карточек создаётся один раз.
- Замер на приставке: повторный запуск экрана источников — 0 обращений к сети.

### 6. Живые часы
- Часы в шапке главного экрана обновляются каждые 30 с и при возврате на экран (раньше застывали на момент создания экрана).

## Исправленные баги
1. **Сброс на главный экран при разворачивании** — лаунчер сбрасывает стек задач, а процесс в фоне не убивается; восстановление теперь работает и через `onNewIntent`.
2. **Видео закрывалось при сворачивании** — восстанавливается с места просмотра.
3. **Zona никогда не кэшировалась** — валидные ответы сети отбрасывались из-за `bindingAdapterPosition == NO_POSITION` у держателя строки; данные и вид разделены.
4. **Фокус улетал из левого меню в центр при зажатой ВВЕРХ/ВНИЗ** — ручная навигация по кнопкам, зажим на краях, переход в центр только ВПРАВО.
5. **Из центрального меню зажатая ВВЕРХ уводила в левое меню** — навигация по «якорям» (герой-кнопка → быстрые кнопки → ряды) с сохранением колонки карточек.
6. **ВЛЕВО из первой карточки источников прыгало на верхнюю панель** — теперь ведёт точно на баннер сайта; из баннера ВПРАВО — обратно к карточкам; с баннера ВЛЕВО фокус зажимается.
7. **«Невидимый фокус»** — пересборка карточек строки (`update`) удаляла фокусную карточку; фокус теперь сохраняется и возвращается на ту же позицию.
8. **Отложенные post-колбэки навигации дёргали фокус назад при зажатой кнопке** — счётчик поколений `navGen`, мгновенная установка фокуса для видимых строк.
9. Часы отставали (см. п. 6 выше).

## Не сделано / ограничения
1. **Последний фикс «проскакивания вверх»** (гашение серии нажатий ВВЕРХ на краю списка, `lastUpKeyAt`) — написан в коде, но **не собран и не установлен**: сборка была прервана. В установленной версии одиночное ВВЕРХ с первого ряда ведёт на вкладки «Фильмы/Сериалы», и зажатие, начатое с первого ряда, может на них проскочить. При следующей сборке зафиксируется автоматически.
2. Таймер включения включает всегда **первый канал** первого плейлиста; выбор канала пользователем не сделан (поля `wake_channel_url/title` в настройках уже готовы).
3. Видео не играет со звуком в фоне при сворачивании — только восстановление с позиции. Для фонового звука нужен foreground-сервис.
4. Точный будильник: на Android 12+ без разрешения `SCHEDULE_EXACT_ALARM` возможна неточность ±несколько минут (на Android 9 вашей приставки — точно).
5. TTL кэшей заданы константами (ленты — 30 мин, карточки — 3 ч), в UI не настраиваются.
6. Баннеры — цветные плитки с названием, не настоящие логотипы сайтов.
7. Состояние каталога внутри сайта (выбранный раздел, страница) при восстановлении не сохраняется — открывается первая страница.
8. WebDAV-бэкап переносит избранное/историю/позиции, но не настройки таймеров и адресов источников.
