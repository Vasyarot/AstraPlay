## 1. Нативные карточки источников

**Путь:** «Фильмы и сериалы» → карточка в ленте → нативный экран AstraPlay (`SourceDetailsActivity`).
WebView на экране описания не создаётся, JavaScript сайта не выполняется. Официальный плеер
источника загружается только после явного «Смотреть» (у Zona/Смотрим — только embed-плеер, без
страницы с рекламой и комментариями).

| Источник | Данные карточки | Сезоны/серии | Просмотр |
|---|---|---|---|
| **Zona** | microdata + блок `entity-desc`: название, оригинал, постер, год, страна, жанры, длительность, рейтинг, описание, режиссёр, актёры | сезоны (`entity-season`), серии страницы сезона, остальные сезоны — ленивые запросы страницы сезона | фильмы — официальный embed-плеер; сериалы — честная пометка (embed 404 у сериалов, подтверждено), кнопка «Открыть страницу источника» |
| **Смотрим (ВГТРК)** | Open Graph + реальное описание бренда (не SEO-шаблон), постер, год | блоки `card-episode`: /video/{id}, название, длительность; серии — официальный плеер `embed.smotrim.ru/iframe/video/id/{id}` | серии и одиночные видео — официальный embed-плеер |
| **Seasonvar** | h1 (рус/англ), og:image, описание | сезоны из `var pl` → публичный plist.txt (JSON серий), с Referer | нативное воспроизведение не реализовано (потоки защищены плеером источника); карточка честно это пишет, воспроизведение — только по явному выбору «Открыть страницу источника» |

- Новые файлы: `data/sources/SourceDetails.kt` (модели, адаптеры парсинга по источникам, загрузчик
  с LRU-кэшем/дедлайном/лимитом размера/отменой), `ui/movies/SourceDetailsActivity.kt`.
- Маршрутизация: поддержанные адреса (определение по домену и пути) открывают нативную карточку
  из ленты, **истории и избранного**; остальные — как раньше, во встроенном браузере.
  Не поддержанные источники (LostFilm, Filmix, HDRezka, Zetflix, …) ведут себя по-старому.
- Отсутствующие поля скрываются; ошибка сети/парсинга — понятный текст + «Повторить»,
  автоматического открытия сайта нет. Антибот-страница и форма входа распознаются и не выдаются за описание.
- Примеры живой разметки (обезличенные) — `app/src/test/resources/sources/`, парсеры покрыты тестами
  (`SourceDetailsParserTest`) именно на этих примерах.

## 2. Исправленные дефекты

1. **Общий пул карточек** — все адаптеры, попадающие в `CardPools.shared`, теперь используют один класс `CardVH` (краш `ClassCastException` невозможен по типам).
2. **Lint RecyclerView** (2 ошибки) — позиции берутся `holder.bindingAdapterPosition` на момент события с проверкой `NO_POSITION`; асинхронные ответы проверяют ещё и идентичность привязанного источника (`boundSourceId`). Подавляющие аннотации не использовались.
3. **«Новинки» Zona** — `pathOverride` больше не перезаписывается `categoryAddress`; путь зеркалам передаётся тот же. Тест: `zonaNoveltyPathIsKeptAndNotReplacedByDefaultCategory`.
4. **Таймауты лент** — у `SourceCatalogLoader` таймауты стали параметрами (8 с для строк сохраняются), и у каждого адреса-кандидата есть свой бюджет из общего дедлайна — медленный основной адрес не лишает зеркало шанса.
5. **«Загрузка…» навсегда** — `TimeoutCancellationException` в строках обрабатывается как понятный отказ с повтором; реальная отмена экрана пробрасывается дальше.
6. **Кэш лент** — ключ включает адрес источника, отрицательный кэш ограничен 5 минутами, при перепривязке строка очищается, устаревшие ответы отбрасываются, смена адреса сбрасывает кэш источника.
7. **Seasonvar** — парсер снова принимает старый формат `/serial-…html` (и новый `/serial/…html`); падающий тест `seasonvarKeepsRussianTextAndDeduplicatesLinks` зелёный.
8. **TMDB** — тип раздела (`/tv/…`) передаётся в парсер; смешанные выдачи разбираются по `media_type` записи. Тесты на «Популярные сериалы»-подобные ответы и trending.
9. **Смена раздела каталога** — поколения запросов: ответ старого раздела отбрасывается, пагинация соответствует выбранному разделу.
10. **SMB-пароль** — в записи/истории/бэкапе попадает адрес без пароля (`SmbServer.urlNoAuth`); данные подставляются только при подключении (`SmbClient.withCredentials`); экспорт дополнительно вычищает пароли из URL.
11. **WebDAV-импорт** — побеждает более свежая запись по дате (позиции и история), дата сохраняется; удалённое локально не воскрешается повторным импортом (только добавление/обновление).
12. **Бэкап** — версия формата (`"v":2`), все позиции (без LIMIT 50), плейлисты и каналы IPTV; импорт с проверкой типов/значений внутри транзакции. Секреты в JSON не пишутся.
13. **WebDAV-HTTP** — соединение с учётными данными требует HTTPS (стандартная проверка сертификатов); HTTP — только отдельной осознанной настройкой `webdavAllowHttp` с предупреждением.

## 5. Сделано / не сделано (итог)

**Запрос пользователя (03.11.2026, после проверки на ТВ):** «обойти платную подписку источника Смотрим». Записан в документ как открытый запрос. Реализация отклонена: обход платного доступа запрещён правилами задачи («Не обходи DRM, платный доступ, CAPTCHA или ограничения аккаунта») и не может быть выполнен — это получение платного контента без оплаты. Легальная альтернатива в приложении есть: «Открыть страницу источника» → «Войти» с аккаунтом подписки, после чего официальный плеер воспроизводит контент.

**Сделано и проверено (юнит-тесты + живая проверка на ТВ):**
- Нативные карточки Zona (фильмы и сериалы с сезонами и ленивыми сериями), Seasonvar (оба движка), Смотрим (серии) — данные конкретной страницы источника, без WebView на экране описания.
- Официальный embed-плеер Zona (фильмы) и Смотрим (серии) — только после явного «Смотреть».
- Маршрутизация лента → карточка → назад, избранное и история → нативная карточка.
- Дефекты 1–13 из проверки, включая найденные во время проверки на ТВ: SEO-заголовок карточек seasonvar.net и недостижимость вкладок с края списка лент.
- 34 юнит-теста зелёные, Lint 0 ошибок, release-сборка установлена на ТВ, крашей нет.

**Сделано, но проверка на устройстве ещё нужна:**
- Исправления 10–13 (SMB-пароль в записях, слияние бэкапа по датам, полный экспорт, WebDAV-HTTPS) — покрыты юнит-тестами на чистых функциях; поведение Store/SMB на живом NAS и реальном WebDAV-сервере не прогонялось.
- Многочасовой стресс-тест лент и карточек не выполнялся.

**Не сделано (с причиной):**
- **Обход платной подписки «Смотрим» — не реализован и реализовываться не будет.** Обход платного доступа — это получение платного контента без оплаты: это нарушение правил источника и законодательства, а исходный промпт задачи прямо запрещает обходить платный доступ и DRM. Приложение вместо этого передаёт пользователю честное состояние: плеер источника сам сообщает «видео доступно только по подписке», а вход в аккаунт с подпиской — через явную кнопку «Войти на сайт» (SourceWebActivity), после чего официальный плеер воспроизводит контент легально.
- Нативное воспроизведение Zona-сериалов и Seasonvar (защищённые плееры источников; не обходилось сознательно).
- Нативные карточки остальных источников (LostFilm, Filmix, HDRezka, Eneyida, AniLibria, Zetflix) — открываются как раньше.
- Сетевая диагностика/прокси — отдельная задача, отложена по условию.
